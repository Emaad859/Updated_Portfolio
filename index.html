  { id: 204, title: "Organic Chemistry Lab Basics",   vector: [0.03, 0.11, 0.18, 0.92] }

// =========================================================================
// 2. Vector Math Algorithm Utilities
// =========================================================================

/**
 * Calculates the dot product of two arrays of numbers.
 * The dot product is the sum of the products of corresponding entries.
 */
const calculateDotProduct = (vectorA, vectorB) => {
  return vectorA.reduce((sum, value, index) => sum + (value * vectorB[index]), 0);
};

/**
 * Calculates the geometric magnitude (length) of a single vector.
 * Computed as the square root of the sum of squared coordinates.
 */
const calculateMagnitude = (vector) => {
  return Math.sqrt(vector.reduce((sum, value) => sum + (value * value), 0));
};

/**
 * Computes the Cosine Similarity between two vectors.
 * Formula: DotProduct(A, B) / (Magnitude(A) * Magnitude(B))
 */
const getCosineSimilarity = (vectorA, vectorB) => {
  const dotProduct = calculateDotProduct(vectorA, vectorB);
  const magnitudeA = calculateMagnitude(vectorA);
  const magnitudeB = calculateMagnitude(vectorB);
  
  // Safeguard calculation loop against division-by-zero runtime exceptions
  if (magnitudeA === 0 || magnitudeB === 0) return 0;
  
  return dotProduct / (magnitudeA * magnitudeB);
};

Holiday Cost Calculator

A Python program built around user-defined functions: separate functions calculate hotel, flight and car rental costs, which a holiday_cost() function combines into a total, driven by user input.

Read the code 
# Function to calculate the cost of the hotel stay
def hotel_cost(num_nights):
    price_per_night = 100  # Example cost per night
    return num_nights * price_per_night

# Function to determine flight cost based on the city
def plane_cost(city_flight):
    flight_prices = {
        "New York": 500,
        "London": 700,
        "Tokyo": 800,
        "Cape Town": 600
    }
    return flight_prices.get(city_flight, "Invalid city")

# Function to calculate car rental cost
def car_rental(rental_days):
    cost_per_day = 50  # Example daily rental rate
    return rental_days * cost_per_day

# Function to calculate total holiday cost
def holiday_cost(num_nights, city_flight, rental_days):
    hotel = hotel_cost(num_nights)
    flight = plane_cost(city_flight)
    car = car_rental(rental_days)

    if isinstance(flight, str):  # Handle invalid city input
        return flight

    total = hotel + flight + car
    return total

# Get user input
print("Welcome to the Holiday Cost Calculator!")
city_flight = input("Enter the city you'll be flying to (New York, London, Tokyo, Cape Town): ").strip()
num_nights = int(input("Enter the number of nights you'll stay: "))
rental_days = int(input("Enter the number of days you'll rent a car: "))

# Calculate total cost
total_cost = holiday_cost(num_nights, city_flight, rental_days)

# Print the holiday summary
if isinstance(total_cost, str):  # Invalid city input
    print(total_cost)
else:
    print("\n==== Holiday Cost Summary ====")
    print(f"Destination: {city_flight}")
    print(f"Hotel cost for {num_nights} nights: ${hotel_cost(num_nights)}")

Student Management System (OOP)

An object-oriented Python program that defines a Student class with attributes for age, name, gender and grades, plus a compute_average() method, then creates and tests student objects.

Read the code 
"""
Student Management Program

This program defines the Student class for managing student data and
computing average grades.
"""


class Student:
    """
    A class representing a student.

    Attributes:
        age (int): The age of the student.
        name (str): The name of the student.
        gender (str): The gender of the student.
        grades (list of int): List of grades obtained by the student.

    Methods:
        __init__(age, name, gender, grades):
            Initializes a new student instance.

        compute_average():
            Computes and prints the average grade of the student.
    """

    # Constructor method
    def __init__(self, age, name, gender, grades):
        """Initializes a new student instance."""
        self.age = age
        self.name = name
        self.gender = gender
        self.grades = grades

    #  Method to calculate average grade
    def compute_average(self):
        """Computes and prints the average grade of the student."""
        average = sum(self.grades) / len(self.grades)
        print("The average for student " + self.name + " is " + str(average))

Caesar Cipher Encoder

Capstone project on cyphers: a Python function that encodes a message using a Caesar shift of 15, wrapping letters around the alphabet while leaving spaces, punctuation and numbers untouched.

Read the code 
def encode_message(message):
    encoded = ""

    for char in message:
        if char.islower():
            shifted = (ord(char) - ord('a') + 15) % 26
            encoded += chr(ord('a') + shifted)
        elif char.isupper():
            shifted = (ord(char) - ord('A') + 15) % 26
            encoded += chr(ord('A') + shifted)
        else:
            # Keep spaces, punctuation, numbers etc. as-is
            encoded += char

    return encoded


# Example usage
original = "Hello, World!"
encoded = encode_message(original)
print("Original message:", original)
print("Encoded message:", encoded)
